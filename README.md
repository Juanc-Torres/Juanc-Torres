## Proyecto de inteligencia artificial

### Gun Detector

<a href="https://www.linkedin.com/posts/jc-torres-rodriguez_python-opencv-yolo-activity-7504862306573578240--h63">
  <img src="https://juanc-torres.github.io/images/projects-ia-cv/gun_detector.png" alt="Interfaz del sistema Gun Detector con detecciones de personas y armas" width="600">
</a>

Prototipo de visión artificial capaz de detectar personas, pistolas y cuchillos en tiempo real utilizando una webcam.

El sistema muestra cuadros verdes alrededor de las personas y cuadros rojos cuando identifica un posible arma. También incorpora un indicador de riesgo, contador de FPS, contador de detecciones y un panel lateral de evidencias.

**Tecnologías:**

`Python` `OpenCV` `Ultralytics YOLO` `PyTorch` `NumPy` `CVAT` `Computer Vision` `Machine Learning`

**Proceso desarrollado:**

- Captura de imágenes mediante webcam.
- Etiquetado del dataset con CVAT.
- Entrenamiento de un modelo YOLO personalizado.
- Separación de imágenes de entrenamiento y validación.
- Validación del modelo con imágenes independientes.
- Integración del modelo en una aplicación de vídeo en tiempo real.
- Creación de una interfaz visual con OpenCV.
- Implementación de un sistema automático de evidencias.

**Funcionalidades:**

- Detección de personas, pistolas y cuchillos.
- Cuadros verdes para personas.
- Cuadros rojos para armas.
- Estado visual de riesgo.
- Confianza de cada detección.
- Contador de FPS y objetos detectados.
- Captura automática de evidencias.
- Panel lateral con historial de detecciones.

[Ver demostración en LinkedIn](https://www.linkedin.com/posts/jc-torres-rodriguez_python-opencv-yolo-activity-7504862306573578240--h63)

> Proyecto educativo. No está diseñado para sustituir un sistema de seguridad certificado ni para tomar decisiones automáticas sobre personas.
